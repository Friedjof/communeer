# Communeer frontend

React + TypeScript + Vite SPA for the Communeer WhatsApp-community admin
dashboard — TanStack Router/Query/Table, Tailwind CSS, shadcn/ui, Recharts.

## Quickstart

```bash
pnpm install
pnpm dev
```

Proxies `/api` to a backend running on `localhost:8000` (see `../backend/`).

## Build / lint

```bash
pnpm build
pnpm lint
```
